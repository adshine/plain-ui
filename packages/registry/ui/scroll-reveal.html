CSS Scroll-Driven Animation Specification

By attaching animation-timeline: view() and specifying animation-range: entry 10% cover 35%, the keyframe progress is mapped directly to the element intersection with the viewport.

/* 1. Keyframe entrance definition */ @keyframes plain-card-reveal { 0% { opacity: 0; transform: translateY(60px) scale(0.92) rotateX(12deg); filter: blur(8px); } 100% { opacity: 1; transform: translateY(0) scale(1) rotateX(0deg); filter: blur(0px); } } /* 2. Bind directly to scroll viewport */ .plain-scroll-card { animation: plain-card-reveal auto cubic-bezier(0.16, 1, 0.3, 1) both; animation-timeline: view(); animation-range: entry 10% cover 35%; }
