Proximity Physics via CSS :has() Combinators

Prior to CSS :has(), creating neighbor-sensitive proximity magnification required subscribing to mousemove events in JavaScript. Today, pure CSS selectors inspect subsequent and preceding sibling states declaratively:

/* 1. Direct hover on active dock item */ .plain-dock-item:hover { transform: translateY(-16px) scale(1.45); } /* 2. Immediate right neighbor (+1 sibling) */ .plain-dock-item:hover + .plain-dock-item { transform: translateY(-9px) scale(1.24); } /* 3. Immediate left neighbor (-1 sibling via :has relational selector) */ .plain-dock-item:has(+ .plain-dock-item:hover) { transform: translateY(-9px) scale(1.24); } /* 4. Second left/right neighbors for organic parabolic decay */ .plain-dock-item:hover + .plain-dock-item + .plain-dock-item, .plain-dock-item:has(+ .plain-dock-item + .plain-dock-item:hover) { transform: translateY(-4px) scale(1.10); }
